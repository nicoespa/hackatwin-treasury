Prefoundly también viene con un servidor MCP. Desde Claude u otro agente podés preguntar el estado, pedir una revisión, ver las transferencias o pausar al agente, sin entrar acá.

claude mcp add prefoundly -- uv run --directory ./hackatwin-treasury treasury-mcp
get_statusSi está activo, sus topes y las transferencias
forecastCuánto se va a pagar en cada cuenta
run_reviewRevisión de prueba o ejecutando
list_transfersTransferencias y en qué estado están
set_autonomyPausar o reanudar al agente
get_limitsTopes y cuentas habilitadas

20.000 usuarios simulados. Cada revisión corre el pronóstico real sobre la historia anterior a ese día. Ninguna transferencia sale a un banco.
